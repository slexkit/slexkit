# 包与安装

- `slexkit` 与 `slexkit/runtime`：HTML 文档运行时和静态检查。
- `slexkit/web-components`：可独立注册的自定义元素。
- `slexkit/custom-elements.json`：供编辑器与工具读取的元素元数据。
- `@slexkit/streamdown`、`@slexkit/assistant-ui` 与 `@slexkit/tiptap`：Markdown 宿主适配器。
- `@slexkit/mcp`：只读文档、示例与静态校验服务。

主题与运行时资源 URL 都由宿主掌控。
