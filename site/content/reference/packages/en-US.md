# Packages

- `slexkit` and `slexkit/runtime`: HTML document runtime and static inspection.
- `slexkit/web-components`: standalone custom elements.
- `slexkit/custom-elements.json`: editor/tool metadata.
- `@slexkit/streamdown`, `@slexkit/assistant-ui`, and `@slexkit/tiptap`: Markdown host adapters.
- `@slexkit/mcp`: read-only docs/examples/static validation.

Theme and runtime asset URLs are host-owned.
