# Design Rationale

HTML/SVG, DOM events, JavaScript modules, custom elements, and slots already provide portable authoring primitives. SlexKit adds isolated lifecycle, streaming-safe commit semantics, component styling, explicit state transfer, and policy bridges without inventing another binding language.
