# Slex 标准产物

标准产物集合描述 `html-1` profile、真实自定义元素目录、沙箱 SDK、静态策略、HTML conformance fixtures 与哈希 manifest。生成过程只序列化元数据，绝不执行 artifact 源码。CLI 的 `--standard` 路径按该 HTML profile 校验，不接受已移除的表达式 schema。
