# Slex Standard Artifacts

The standard artifact set describes the `html-1` profile, actual custom-element catalog, sandbox SDK, static policy, HTML conformance fixtures, and a hash manifest. Generation serializes metadata only and never executes artifact source. The CLI `--standard` path validates against this HTML profile; it does not accept the removed expression schema.
