# SlexKit 0.5 HTML runtime contract

This document records the 0.5 candidate behavior after the HTML-first migration. The active implementation requirements are in `html-migration-contract.md`.

## Source format

A source is a string containing an HTML fragment. Native HTML/SVG, the documented `slex-*` custom elements, `<style>`, and inline `<script>` are allowed subject to static policy. Every executable inline script runs as a module. Object-tree input, expression-string attributes, state-only source, and legacy fallback are invalid.

## Host lifecycle

`createSlexKitMarkdownRuntimeHost(options)` exposes `configure`, `getMode`, `mountBlock`, `disposeBlock`, `disposeArtifact`, `disposeAll`, `updateArtifact`, and `resetArtifact`.

- Each block owns an isolated frame/document by default.
- A host supplies `secureFrame.runtimeUrl` and may supply `styleUrl`.
- Missing or failed runtime assets fail closed.
- `phase: "preview"` performs static validation and leaves the last committed document interactive.
- `phase: "commit"` applies a valid source revision.
- Stable block IDs and stable element `id`/`data-key` preserve compatible instances and visible control state where supported.
- `resetArtifact()` reapplies source defaults.
- Changed setup scripts dispose before replacement. Arbitrary closure state is not preserved.

`mount(source, container, options)` uses the same document host and returns a disposer/handle with `ready`, `update`, `reset`, and `snapshot` operations.

## Static inspection

`inspectSlexSource`, `parseSlexSource`, and `validateSlexSource` parse and inspect HTML/JavaScript without executing scripts. They work in Node without a DOM. Static checks reject external scripts/imports, event-handler attributes, embedded frames/plugins, navigation metadata, and executable URL schemes. Static validity does not make generated code trusted.

## Guest SDK

The isolated document exposes `slex.root`, a scope `AbortSignal` at `slex.signal`, `slex.onDispose`, `slex.onSnapshot`, `slex.onRestore`, policy-gated `slex.api`, and artifact-local `slex.shared.get/set/subscribe`. Shared values are JSON data. There is no implicit state object or binding grammar.

## Security boundary

Payload fetch, image, font, external script, and external link resource loads are denied by the frame policy in the supported browser conformance suite. Approved requests use the host policy bridge. This is not a complete egress firewall: a payload can navigate its own iframe with `location.href`, which can issue a request. Message traffic validates source window, channel token, request ID, revision, and shape. Stale responses cannot overwrite a later revision. The runtime does not provide CPU preemption; hostile code requires external browser/process network controls and timeouts.

The authoring/profile identifier is `html-1`; the internal frame channel is `slexkit-html-v1`. Former `0.1` protocol references apply only to historical releases.
